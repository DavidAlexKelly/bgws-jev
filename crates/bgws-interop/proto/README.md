# Federate Protocol messages (HLA 4)

Reprinted with permission from IEEE 1516.1(TM)-2025.

`RTIambassador.proto`, `FederateAmbassador.proto` and `datatypes.proto` are
the IEEE 1516.1-2025 Federate Protocol API, unchanged, as published in Pitch
Technologies' FedProClient (https://github.com/Pitch-Technologies/FedProClient,
commit 03e549a9e63db239be1828c58886d59791976bcf, 2026-10-20). The IEEE's
licence is in `LICENSE-IEEE_1516-2025.txt`. `build.rs` compiles them to Rust
with `protox` and `prost`.
