# Docs

- `design/RUST_ENGINE.md`: the engine's design, which the code cites by
  section (§). `MULTI_DOMAIN_PLAN.md`, `DECISION_FLOW_GRAPHS.md` and
  `SIDE_PICTURE.md` are the earlier plans it builds on.
- `research/MODERN_WARFARE_REFERENCE.md`: the sources behind the figures and
  the vignettes' bands (the `P…` and `R…` references).
- `BGWS - Rulebook.pdf`: the original tabletop rules.

These were written while the engine was being ported from an earlier
TypeScript implementation. Paths and some context in them describe that
time; `README.md` at the root and `protocol/PROTOCOL.md` describe the
project as it is.
